# Правила маршрутизации чата (KB v2)

1. Если пользователь явно указал **катер** — не уточнять «зал или катер».
2. Если пользователь явно указал **зал** — не уточнять «катер или зал».
3. Если спрашивает «что взять?» без локации — уточнить «на катер или в зал?».
4. Если хочет записаться, но не указал куда — спросить «катер или зал?» + кнопки.
5. Запись на **катер** — короткий ответ + `cta_type: booking_boat`.
6. Запись в **зал** — короткий ответ + `cta_type: booking_gym`.
7. Вопрос про **проект** — ответ по проекту + ссылка/CTA проекта.
8. **Медицинский** вопрос — без диагнозов, предложить предупредить тренера.
9. **Юридический / оплата / возврат** — только утверждённый текст из KB.
10. **Нет данных** — честно сказать, что уточним у менеджера.
