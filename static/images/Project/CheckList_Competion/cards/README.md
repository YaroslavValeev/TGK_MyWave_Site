# Иллюстрации карточек чек-листа организатора

Положите сюда файлы с **именем = `id` чекбокса** в HTML (без расширения в имени логического ключа).

Поддерживаемые расширения: `.jpg`, `.jpeg`, `.png`, `.webp`.

Пример: для `<input id="judge-1-1" …>` файл — `judge-1-1.jpg`.

После добавления файла перезагрузите страницу `/projects/checklist-org`: фон блока `.wake-checklist__card-media` подставится автоматически.
