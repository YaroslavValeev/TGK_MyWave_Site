Чек-лист организатора соревнований по вейксерфингу

Условия для соревнований по вейксерфингу. Данный чеклист содержит необходимые условия и требования для организации профессиональных соревнований. Используйте его как руководство при подготовке мероприятий.

Полная интерактивная версия и скачивание PDF: на сайте по адресу страницы проекта «Чек-лист для организатора соревнований» (раздел Проекты).

Структура чек-листа по эталону:

  1. Судьи
  2. Акватория
  3. Площадка (территория)
  4. Выделенная территория для организаторов
  5. Выделенная территория для судей
  6. Безопасность
  7. Медицина
  8. Оборудование и техника
  9. Инфраструктура и логистика
  10. Приложение и онлайн-сервисы
