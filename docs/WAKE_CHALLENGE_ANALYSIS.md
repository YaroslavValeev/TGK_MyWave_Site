## 3. Баг: «Подробнее» — ничего не происходит

### Причина
Карточка имеет класс `js-expandable-card`. В `services-expand.js` на карточку вешается обработчик `click`:

```js
card.addEventListener('click', function (e) {
  if (e.target.closest('.book-now, .btn, a, ...')) return;
  card.classList.toggle('is-expanded');
});
```

Логика предполагает: при клике по `.btn` или `a` — `return` без toggle, переход по ссылке должен сработать.  
На практике клик может обрабатываться неоднозначно (например, при попадании в граничную зону между кнопкой и областью карточки, при touch-событиях), из-за чего вместо перехода происходит toggle карточки и пользователь видит «ничего не происходит» (страница не меняется).

### Решение
Добавить `event.stopPropagation()` на CTA-ссылки в блоке действий карточки, чтобы клик по кнопкам/ссылкам не «всплывал» до обработчика карточки. Тогда:
1. Клик по «Подробнее» → переход по `href`
2. Клик по области карточки (не по CTA) → раскрытие/сворачивание карточки
