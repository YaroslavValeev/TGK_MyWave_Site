# Письмо команде MyWaveTour: кемпы не отображаются на сайте

**Кому:** разработчикам MyWaveTour (Camp API)
**От:** команда сайта MyWave (mywavewake.ru)
**Дата:** 25.09.2026

---

Здравствуйте!

На сайте https://mywavewake.ru/camps сейчас показывается «Пока нет опубликованных кемпов». Связь с вашим API работает: авторизация проходит, ошибок 401/5xx и таймаутов нет. Но ни один кемп из ответа не проходит фильтры витрины. Помогите разобраться, где причина: в данных или в нашем понимании контракта.

## Как сайт читает кемпы

- `GET {MYWAVE_TOUR_CAMPS_API_URL}?limit=25&offset=N` с заголовком `Authorization: Bearer <token>`, листаем по `next_offset`, пока он не станет `null`.
- Карточка кемпа: `GET {MYWAVE_TOUR_CAMPS_API_URL}/{id}`.
- Ожидаемый формат ответа списка: `{"items": [...], "next_offset": null}`.

## Какие кемпы сайт показывает

Кемп попадает на витрину, только если выполнены все условия:

| Поле | Условие |
|---|---|
| `publication_status` | `published` (или поле отсутствует) |
| `content_rights_status` | не `restricted` |
| `sport` | `wakesurf`, `wakeboard` или `mixed` (или поле пустое) |
| `audience_language` | содержит `ru` (или поле пустое) |
| `end_date` (если нет — `start_date`) | сегодня или позже; кемп без дат тоже показываем |
| `id` / `title` | не тестовые: без `mvp`, `test`, `demo`, `sample`, `synthetic`, «пилотный», «тестовый» |

## Вопросы

1. Сколько кемпов сейчас отдаёт API по нашему токену, и есть ли среди них опубликованные кемпы с датами **после 25.09.2026** (осень/зима 2026, сезон 2027)?
2. Если кемпы на будущее есть: какие у них значения `publication_status`, `sport`, `audience_language`, `end_date`? Если значения отличаются от таблицы выше (например, `status` вместо `publication_status` или `sports` списком), пришлите актуальную схему — подстроим сайт.
3. Остаётся ли в силе особенность, что `limit=100` иногда возвращает пустой список, а `limit=5` — данные? Мы на всякий случай запрашиваем страницы по 25.
4. Планируется ли наполнение каталога на следующий сезон, и к какой дате?

Будет достаточно одного примера JSON реального кемпа на будущие даты (без персональных данных организаторов). По нему мы сразу проверим, пройдёт ли он фильтры.
