## 3. Исправления по модалкам Camp и «Тренер на выезде»

| Способ закрытия | Реализация |
|-----------------|------------|
| **Крестик** | Обработчик на `.close-modal`; добавлено делегирование на `document` для надёжности |
| **Overlay** | Клик по `div.modal` (тёмная зона) закрывает модалку |
| **Escape** | Обработчик `keydown` на `Escape` закрывает все модалки |

**Технические правки:**
- `static/js/booking.js`: `hideAllModals` — сразу скрывает модалки (убрана задержка 300 ms), добавлен делегированный обработчик для `.close-modal`.
- `static/js/modals-close.js`: отдельный скрипт с делегированием для закрытия по крестику, overlay и Escape.
- `templates/base.html`: подключён `modals-close.js`.
- `aria-label="Закрыть"` для `.close-modal` в `modalCamp`, `modalCoachTriper`, `modalConsulting`.
