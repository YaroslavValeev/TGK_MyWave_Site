# Wake Challenge (WSC) — обязательные требования спринта

**Скоуп:** правим только страницу Wake Challenge и её файлы. Остальной сайт не трогаем.

**Порядок:** спринт стартует только после закрытия чек-листа (PR + QA + «блокеры = 0» + merge).

---

## 1) Что должно быть исправлено/добавлено

### 1.1 HERO

- Заголовок по центру.
- Тень/контраст распространяются на **всю область** букв заголовка и подзаголовка (чтобы читалось на фоне).
- **Убрать из HERO** лишние бейджи/строки:
  - «Веса 40/30/30»
  - «Outliers: z-score ≥ …»
  - «Контакты: …»  
  (веса 40/30/30 остаются стандартом, но живут в разделе «Судейство/Правила», а не в HERO-бейджах.)

### 1.2 Смысл проекта (обязательный блок)

Коротко и ясно: соревнование тренеров России по мастерству преподавания; выявляем самого эффективного тренера; коллективно собираем методичку; строим справедливый рейтинг; усиливаем Россию в мировом вейксерфинге.

### 1.3 Обязательные секции на странице

- «Программа финального дня»
- «Календарь вебинаров»

### 1.4 Кнопки/переключатели/формы

- Починить неработающие CTA/табы регистрации/submit (критично).
- Логика ролей: участник / тренер / спонсор — понятный путь, корректная отправка, без 400/CSRF сбоев на странице проекта.

### 1.5 Спонсорство

- Витрина пакетов + цены видимы.
- KPI-витрина для спонсоров — закрытый раздел (если реализовано: доступ только по логике проекта; если нет — минимум текстом объяснить, что доступ «по запросу»).

### 1.6 Контакты проекта

- Email и телефон — в блоке контактов (актуальные).

### 1.7 SEO

- Корректный canonical и meta на канонический домен.
- Страница индексируется как отдельный проект, без дублей.

## 2) Роли subagents на Wake Challenge

| Subagent | Задача |
|----------|--------|
| **A** | slug/URL/роуты/витрина проекта, каноник, отсутствие «левых» редиректов |
| **C** | структура секций/семантика, корректная сборка контента |
| **D** | HERO и стили (строго изолированно в рамках страницы) |
| **F** | meta/canonical/OG/Twitter |
| **E** | QA всех кнопок/табов/submit, консоль/network |

---

## 3) Пакет файлов для точечного патч-плана

После закрытия чек-листа команда готовит пакет файлов Wake Challenge по списку в **`docs/WAKE_CHALLENGE_FILES_FOR_PATCH_PLAN.md`** (шаблон, стили, роут, JS, конфиги, контент). Ярослав по этому пакету выдаёт правки «файл → блок → замена» + DoD 10/10.

**Ответственный за артефакт:** лид/команда — пакет файлов по чек-листу из `WAKE_CHALLENGE_FILES_FOR_PATCH_PLAN.md`.
