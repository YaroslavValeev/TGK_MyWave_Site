# WakeSurf Safari — обязательные требования спринта №2

**Скоуп:** работаем строго в рамках страницы Safari. Остальной сайт не трогаем.

**Порядок:** спринт стартует **после** Wake Challenge (по очереди).

---

## 1) Что должно быть на странице

1. **HERO** + понятное позиционирование.
2. **Визуализация маршрута** (карта/поинты/остановки).
3. **Программа по дням/стопам.**
4. **Пакеты участия** (что входит).
5. **Лид-форма** (выбор пакета → контакт → подтверждение).
6. **FAQ** + условия/безопасность/что взять с собой.
7. **Для партнёров** — блок «интеграции в маршрут» (минимум: оффер + форма запроса).
8. **SEO:** canonical/meta/OG.

## 2) Роли subagents на WakeSurf Safari
