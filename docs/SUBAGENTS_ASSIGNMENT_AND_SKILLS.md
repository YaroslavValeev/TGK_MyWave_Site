## 0) Базовые правила (обязательные для всех)

1. **Скоуп:** правки только в рамках трёх проектов: contest-org-checklist, Wake Challenge, WakeSurf Safari. Никаких побочных правок главной, услуг, чата, аналитики, рекомендаций.
2. **Эталон чек-листа:** файл «Чек-лист Организатора — Условия для соревнований по вейксерфингу.html» — вёрстка/структура/смысл должны совпадать.
3. **Без глобальных поломок:** CSS — специфичные селекторы или отдельный CSS проекта; роуты/редиректы — только для нужных slugs/путей.
4. **Документация:** каждый subagent оставляет в PR короткое «что сделал / что проверить». В конце — единый QA-протокол.

## 1) Назначение исполнителей и Skills

### Subagent A — Routing / Showcase source

**Skills:** Flask routing, витрина проектов, slug/URL, единый source-of-truth.

**Задачи:**
- Контроль канонических и стабильных URL для всех трёх проектов (contest-org-checklist, Wake Challenge, WakeSurf Safari).
- **Раздел «Проекты»:** единый источник 5 проектов для главной и `/projects`; `page_url`/slug и каноники согласованы.
- Никаких побочных правок вне трёх проектов и раздела «Проекты».
- Для Wake Challenge и WakeSurf Safari — проверка доступности по правильным slug и корректность витрины.

**Definition of Done:**
- Чёткий список URL для трёх проектов + проверенные 301 (где нужно).
- Главная и `/projects` рендерят один и тот же список из одного источника (5 проектов).

---

### Subagent B — PDF / Backend robustness

**Skills:** WeasyPrint, обработка ошибок, HTTP headers, base_url, кэширование, безопасность.

**Задачи:**
- Обработка ошибок PDF (503 при отсутствии WeasyPrint, страница при ошибке генерации).
- Корректность заголовков скачивания и имени файла.
- Резолвинг статики внутри PDF (base_url).

**DoD:**
- PDF стабильно генерируется при установленном WeasyPrint.
- При отсутствии WeasyPrint — корректная fallback-страница (не 500).

---

### Subagent C — Templates / HTML structure

**Skills:** Jinja2, семантика, partials, аккуратная интеграция в index/projects.

**Задачи:**
- Контент чек-листа в общем фрагменте; единая структура HTML/PDF; сверка с эталоном.
- **Раздел «Проекты»:** шаблон секции Projects на главной (контейнер карусели); шаблон карточки проекта (унифицированный); шаблон модалки проекта (скелет) + data-атрибуты для JS.
- Для Wake Challenge / Safari — структура страниц без дублирования, где возможно.

**DoD:**
- HTML и PDF чек-листа используют общий контент без расхождений.
- Разметка читаемая и поддерживаемая.
- Секция «Проекты» и страница `/projects` используют общие partials/карточки; модалка имеет скелет и data-атрибуты для загрузки контента/галереи.

---

### Subagent D — UX/UI / CSS

**Skills:** адаптив, типографика, micro-interaction, «полупрозрачные» controls, CSS-изоляция, print styles.

**Задачи:**
- Правки внешнего вида только в контейнере проекта (чек-лист, Wake Challenge, Safari).
- **Раздел «Проекты»:** стрелки/ползунок карусели (десктоп) + мобильные состояния; стили модалки и галереи (карточка и модалка); проверка, что не ломаем существующие reviews/events/blog.
- Проверка, что print-стили не ломают другие страницы при печати.

**DoD:**
- Визуально чисто на десктопе и мобильном.
- Печать/экспорт в PDF корректны (чек-лист).
- Карусель и модалка «Проекты» стилизованы изолированно; регресс по другим каруселям/секциям отсутствует.

---

### Subagent E — QA / Regression

**Skills:** чек-листы, консоль/сеть, mobile/desktop, a11y sanity checks, тест-протоколы, редиректы, кросс-браузерность.

**Задачи:**
- Финальная проверка чек-листа по протоколу (см. QA-протокол ниже); вердикт: «можно закрывать» / «есть блокеры».
- **Раздел «Проекты»:** регресс по главной — карусель работает, модалка открывается/закрывается, свайп листает; на мобилке свайп галереи не открывает модалку случайно; консоль без ошибок, сеть без 404 по картинкам; ничего не сломано в других секциях.

**DoD:**
- Принесён QA-пакет по чек-листу: скриншоты + итоговый PDF + заполненный чек-лист ОК/не ОК.
- По «Проектам»: сценарии карусель/модалка/свайп проверены; регресс зафиксирован или отсутствует.

---

### Subagent F — SEO

**Skills:** title/description/canonical, OG/Twitter, разметка для проектов, sitemap.

**Задачи:**
- Проверка мета-тегов чек-листа; подготовка SEO-каркаса для Wake Challenge и WakeSurf Safari.
- **Раздел «Проекты»:** `/projects` и `/projects/<slug>` — корректные meta/canonical/OG; модалка не должна создавать дублей/индексации (она не URL-страница).

**DoD:**
- Title / Description / Canonical / OG / Twitter корректны и уникальны для каждой страницы проекта.
- Модалка не создаёт индексируемых дублей; страницы проектов имеют канонические URL.

---

### Subagent G — Frontend JS (раздел «Проекты», обязателен)

**Skills:** Vanilla JS, touch/swipe, scroll-snap, modal accessibility, event handling.

**Задачи:**
- Реализовать карусель проектов на главной: кнопки + range + snap.
- Реализовать мини-галерею в карточке и большую галерею в модалке.
- Разрулить конфликт «свайп/клик»: свайп листает фото, клик по карточке открывает модалку; клик по элементам галереи (стрелки/точки) не открывает модалку.
- Закрытие модалки (Esc/overlay), фокус-ловушка, body scroll lock.
- Опционально: deep-link через hash (открыл модалку → `#project=<slug>`, Back закрывает).

**DoD:**
- Карусель листается (стрелки, range, свайп на мобилке); snap по карточкам.
- Мини-галерея в карточке листается без открытия модалки; клик по карточке открывает модалку.
- Модалка открывается/закрывается штатно; фокус и scroll lock работают; консоль без ошибок.
