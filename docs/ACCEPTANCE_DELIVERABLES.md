# Definition of Done — приёмка 10/10

Ярослав, финальный DoD по блоку: лид-модалки, карусели, Wave Cards. Что сделано в коде и что прислать для закрытия приёмки.

---

## 1) Лид-модалки (Camp / Тренер на выезде / Консалтинг) — «без мигания» окончательно

**Цель:** модалки не открываются и тут же не закрываются из-за конфликтов (booking.js vs lead-forms.js).

**Зафиксировано в коде:**

1. **Крестик лид-модалок не ловит booking.js**  
   У лид-модалок класс **`close-modal` убран**. Оставлены только **`lead-modal-close`** и **`modal-close`**.  
   booking.js вешает обработчик на **`.close-modal`** — крестики лид-модалок больше не попадают под него.

2. **stopImmediatePropagation + capture** на клике по закрытию лид-модалок — оставлены (страховка от чужих обработчиков).

3. **Открытие лид-модалок** (кнопки Camp / Выезд / Консалтинг):
   - не триггерит глобальные закрыватели (capture + stopImmediatePropagation на кнопке);
   - не ломает скролл/overflow (lead-forms выставляет `body.style.overflow` при открытии/закрытии);
   - не конфликтует с модалками бронирования (booking.js закрывает только 4 модалки по id).

4. **Закрытие:** крестик / фон (backdrop) / Escape — работают одинаково на всех трёх модалках.

**Проверка вручную:** открыть Camp → Выезд → Консалтинг по кнопкам; закрыть крестиком, фоном, Escape. Модалка не должна мигать и сразу закрываться.

---

## 2) Карусели на главной — «Товары» и «Проекты» (и не ломаем «Услуги»)

**Поведение:**

1. В секциях **«Товары»** и **«Проекты»** (и в **«Услуги»**):
   - горизонтальный трек (`.carousel-track`, `overflow-x: auto`);
   - видимые кнопки **‹ / ›**;
   - прокрутка трека по клику (`scrollBy` ±320px, smooth);
   - кнопки **disabled** на краях (в начале ‹, в конце ›).

2. На тач-устройствах: **свайп** по треку работает нативно (`overflow-x: auto`, `-webkit-overflow-scrolling: touch`); кнопки остаются и работают.

3. Логика каруселей в **одном** скрипте `services-carousel.js`: отдельный блок для `.js-service-carousel` (слайдер изображений, если есть) и общий блок для **`.services-carousel`**, **`.products-carousel`**, **`.projects-carousel`** (прокрутка трека). Конфликтов нет; «Услуги» не ломаются.

4. Высота блоков и наложения на чат не менялись; при появлении «прыжков» — проверить только добавленные стили в `services-carousel.css` для products/projects.

---

## 3) Wave Cards — только dev-only

**Зафиксировано:**

1. **Production:**
   - Wave Cards **не показывается** ни на главной, ни в магазине;
   - прямой URL **`/shop/product/wave-cards`** отдаёт **404**.

2. **Dev/staging** (или `SHOW_DEV_PRODUCTS=True`):
   - Wave Cards **виден в магазине** с плашкой **«В разработке»** и кнопкой **«Скоро»** (неактивная, не ссылка);
   - на странице товара `/shop/product/wave-cards` — та же плашка и «Скоро» вместо «Купить».

3. **На главной** Wave Cards **не добавлен** в превью (в витрину не засоряем).

Если на скринах Wave Cards всё ещё всплывает на prod — проверить: один ли шаблон главной (`templates/index.html`), один ли источник товаров (`get_products_preview` + `PRODUCTS` в `app/routes/shop.py`), нет ли кэша/другой ветки.
