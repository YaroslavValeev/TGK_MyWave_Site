## 1. Проведённая проверка

### 1.1 Код работы с таблицами (Google Sheets)

- **`app/services/blog/publish.py`**
  - Валидация `row_number`: приоритет колонке из таблицы, проверка `int >= 2`, коды ошибок `WP_ROW_NUMBER_*`.
  - Перед любым writeback вызывается `_validate_writeback_schema(headers)` — проверка обязательных колонок.
  - Поиск строки только по `row_number`: `_find_record_by_row_number`, `_find_record_by_sheet_row_number` (без привязки к индексу массива).
  - `ack_publish()` пишет только site-owned поля: `published_posts`, `published_at`, `canonical_url`, `publish_attempts`, `publish_last_try_at`, `publish_error`, lock-поля.
  - `record_publish_error` / `record_publish_error_by_id`: при отсутствии `row_number` используется поиск по уникальному `id`, запись только в найденную строку.
  - Fallback `index+2` включён только в тестовом режиме (`_is_test_row_index_fallback_enabled()`).

- **`app/services/google.py`**
  - `read_sheet()`: поиск строки заголовков по эвристике (ожидаемые колонки `id`, `status`, `published_posts`, и т.д.), первые 400 строк, первые 80 колонок.
  - В каждую запись записывается `_sheet_row_number` (1-based номер строки листа) для корректного сопоставления с `row_number`.

- **Запись в таблицу**
  - Единственная точка записи — `update_sheet_cells()` → `batchUpdate` по диапазонам вида `{sheet_name}!{col_letter}{row_number}`.
  - Индексы колонок берутся из текущих headers при каждом вызове (без кеша по именам).

### 1.2 Обнаруженное и исправленное расхождение

- В `_get_public_blog_base_url()` fallback был задан как `https://mywavetraining.ru` (с буквой «a»).
- По контракту и Decision Log canonical-домен — `mywavetreaning.ru` (с буквой «e»).
- **Исправлено:** fallback заменён на `https://mywavetreaning.ru`.

### 1.3 Оценка «на 100%»

- **Логика работы с таблицами (чтение, поиск строки, writeback по `row_number`, схема, ownership)** — реализована в соответствии с P0-контрактом; после исправления домена поведение согласовано с документацией.
- **100% уверенность** возможна только после повторяемых успешных прогонов на проде (успешный writeback + кейс без `row_number`) и стабильной работы в боевом режиме. Текущая реализация даёт основание считать интеграцию с таблицами **отлаженной в рамках P0**, при условии что:
  - Parser Bot заполняет `row_number` в каждой строке;
  - в листе `raw_feed` присутствуют все обязательные колонки из `RAW_FEED_REQUIRED_WRITEBACK_COLUMNS`;
  - на проде выполнен и зафиксирован контрольный прогон (как в P0_DEPLOYMENT_STATUS / Decision Log).

Ниже — краткий итог выполненной работы по P0 и текущая оценка надёжности работы с таблицами.

**Что сделано со стороны сайта**

1. **Релиз P0 в main**  
   Ветка с P0-изменениями (PR #7) смержена в `main`. В проде используется логика безопасной обратной записи в Google Sheets (лист `raw_feed`).

2. **Работа с таблицами**
   - Сайт читает данные только через текущие заголовки листа (источник истины — сам лист).
   - Номер строки для записи берётся **только** из колонки `row_number` (целое число ≥ 2). Запись в таблицу идёт строго по этому номеру строки.
   - Перед любой записью проверяется наличие обязательных колонок; при их отсутствии запись не выполняется, в `publish_error` выставляется код (в т.ч. `WP_SCHEMA_MISMATCH`).
   - После успешной публикации в таблицу записываются только поля, за которые отвечает сайт: `published_posts`, `published_at`, `canonical_url`, `publish_attempts`, `publish_last_try_at`, `publish_error`, а также снятие lock (если колонки есть).
   - Если `row_number` отсутствует или невалиден, обратная запись по такой строке не выполняется; при необходимости ошибка фиксируется по уникальному `id` (без записи «в чужую» строку).

3. **Canonical URL**
   - Формируется как `{base_url}/blog/{slug}`.  
   - По контракту canonical-домен — `mywavetreaning.ru`; fallback в коде приведён к этому значению.

4. **Документация и статус**
   - Decision Log (R2/P0), P0_DEPLOYMENT_STATUS, P0_STATUS и инструкции по редиректам/деплою/контрольному прогону обновлены.
   - Закрытие P0 со стороны Parser Bot зафиксировано (в т.ч. интеграционный тест по строке 200).

**Проверка перед отправкой письма**

- Обнаружено и исправлено расхождение: в коде fallback для base_url был задан как `mywavetraining.ru`; заменён на `mywavetreaning.ru` в соответствии с контрактом.
