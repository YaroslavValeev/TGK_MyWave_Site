# WakeSurf Challenge 2025

## О проекте

WakeSurf Challenge 2025 — это спортивно-образовательная программа для тренеров и райдеров, направленная на развитие единой методики преподавания, прозрачное судейство и создание медиа-витрины KPI для партнёров.

Проект объединяет тренировки, вебинары, прозрачное судейство по системе 40/30/30 (сложность / качество / стиль) и медиа-витрину для демонстрации результатов и достижений участников.

## Как это работает

Проект состоит из нескольких этапов:

1. **Регистрация** — участники, тренеры и спонсоры подают заявки через форму на сайте
2. **Тренировки** — регулярные занятия с профессиональными тренерами
3. **Вебинары** — образовательные сессии по методике преподавания и судейству
4. **Судейство** — прозрачная система оценки с использованием единых критериев
5. **Медиа** — создание контента и витрины достижений участников

## Регистрация

Для участия в проекте необходимо заполнить форму регистрации на сайте. Доступны три варианта участия:

- **Участник** — для райдеров, желающих улучшить свои навыки
- **Тренер** — для профессионалов, готовых поделиться опытом
- **Спонсор** — для компаний, заинтересованных в поддержке проекта

## Судейство

Система судейства основана на трёх критериях с весами 40/30/30:

- **40% — Сложность** — техническая сложность выполненных элементов
- **30% — Качество** — чистота исполнения, техника
- **30% — Стиль** — артистизм, оригинальность, презентация

Для обеспечения справедливости используется система калибровки и контроль разброса оценок (z-score).

## Медиа

В рамках проекта создаётся медиа-витрина с результатами участников, достижениями и контентом для партнёров. Все материалы публикуются на сайте проекта и в социальных сетях.

## Партнёрам

Проект открыт для партнёрства. Мы предлагаем несколько пакетов спонсорства с различными условиями и возможностями размещения логотипов и упоминаний.

Для обсуждения условий партнёрства свяжитесь с организаторами по указанным контактам.

## FAQ

### Как зарегистрироваться?

Заполните форму регистрации на сайте, выбрав подходящий вариант участия (участник, тренер или спонсор).

### Какие документы нужны для участия?

После регистрации вы получите пакет документов с подробной информацией и инструкциями. Материалы доступны для скачивания в разделе «Документы».

### Как проходит судейство?

Судейство основано на системе 40/30/30 (сложность / качество / стиль) с использованием единых критериев и калибровки судей.

### Где можно посмотреть результаты?

Результаты и медиа-материалы публикуются на сайте проекта и в социальных сетях.
