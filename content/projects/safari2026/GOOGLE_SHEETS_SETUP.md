# Настройка Google Sheets для Wake Surf Safari 2026

## Инструкция по созданию листов

Создайте следующие листы в вашей Google Таблице (SPREADSHEET_ID):

## 1. Лист `Safari_Leads` (Участники)

**Назначение:** Регистрация участников проекта

**Структура колонок (заголовки в первой строке):**

| № | Название колонки | Тип данных | Описание |
|---|------------------|-----------|----------|
| 1 | Дата регистрации | Текст | Формат: YYYY-MM-DD HH:MM:SS |
| 2 | ФИО | Текст | Полное имя участника (до 100 символов) |
| 3 | Телефон | Текст | Нормализованный формат: +7XXXXXXXXXX |
| 4 | Email | Текст | Email адрес (в нижнем регистре) |
| 5 | Формат участия | Текст | Варианты: Полный маршрут (8 дней), Частично (1/3/5/7 дней), Не указан |
| 6 | Уровень катания | Текст | Новичок, Средний, Продвинутый, Профессионал, Не указан |
| 7 | Опыт (лет) | Текст | Количество лет опыта в вейксерфинге |
| 8 | Город | Текст | Город проживания |
| 9 | Возраст | Текст | Возраст участника |
| 10 | Источник информации | Текст | Откуда узнали о проекте (Instagram, Telegram, YouTube, и т.д.) |
| 11 | Instagram | Текст | Instagram аккаунт (@username) |
| 12 | Telegram | Текст | Telegram аккаунт (@username) |
| 13 | Комментарий | Текст | Дополнительная информация (до 500 символов) |
| 14 | Согласие на обработку данных | Текст | Да/Нет |
| 15 | Согласие на медиа | Текст | Да/Нет |
| 16 | IP адрес | Текст | IP адрес пользователя |
| 17 | Тип устройства | Текст | mobile/tablet/desktop |
| 18 | Браузер | Текст | Chrome, Firefox, Safari, и т.д. |
| 19 | Referrer | Текст | Источник перехода |
| 20 | UTM Source | Текст | UTM метка источника |
| 21 | UTM Medium | Текст | UTM метка канала |
| 22 | UTM Campaign | Текст | UTM метка кампании |

## Быстрая настройка

### Вариант 1: Ручное создание

1. Откройте вашу Google Таблицу (SPREADSHEET_ID)
2. Создайте 4 новых листа с указанными названиями
3. Скопируйте заголовки из примеров выше в первую строку каждого листа
4. Закрепите первую строку (Вид → Закрепить → 1 строку)

### Вариант 2: Импорт шаблона CSV

Вы можете создать шаблон CSV для каждого листа и импортировать его.

## Аналитические возможности

Собранные данные позволяют проводить:

### Для участников:
- **Демографический анализ:** возраст, город, уровень катания
- **Анализ источников:** откуда приходят участники (UTM, referrer)
- **Сегментация:** по уровню, опыту, формату участия
- **Конверсия:** по источникам, устройствам, браузерам

### Для партнёров:
- **Анализ рынка:** отрасли, размеры компаний, бюджеты
- **Воронка продаж:** от заявки до решения
- **Сегментация:** по пакетам, бюджетам, срокам

### Для медиа:
- **Анализ охвата:** общая аудитория, охват по платформам
- **География:** распределение аудитории медиа-партнёров
- **Типы контента:** какие форматы предпочтительнее

### Общая аналитика:
- **Каналы привлечения:** эффективность UTM кампаний
- **Устройства:** мобильные vs десктоп
- **География:** по IP адресам (можно добавить геолокацию)

---

## Важные замечания

1. **Названия листов должны быть точными:** `Safari_Leads`, `Safari_Partners`, `Safari_Media`, `Safari_Feedback` (с учётом регистра)

2. **Порядок колонок важен:** Данные сохраняются в том порядке, в котором они указаны в коде. Если порядок колонок не совпадает, данные будут сохранены неправильно.

3. **Заголовки в первой строке:** Рекомендуется закрепить первую строку для удобства просмотра.

4. **Права доступа:** Убедитесь, что сервисный аккаунт (service_account.json) имеет права на запись в эту таблицу.

5. **Тестирование:** После создания листов протестируйте отправку форм, чтобы убедиться, что данные сохраняются корректно.

6. **GDPR/Персональные данные:** IP адреса и другие персональные данные должны обрабатываться в соответствии с законодательством о защите данных.

## Дополнительные настройки (опционально)

### Форматирование дат

Вы можете настроить форматирование колонок с датами:
- Выделите колонку с датами
- Формат → Число → Дата и время

### Условное форматирование

Для удобства можно добавить условное форматирование:
- Новые строки (последние 10) — жёлтый фон
- Строки старше 7 дней — серый фон
- По типу устройства — разные цвета

### Фильтры

Добавьте фильтры к заголовкам:
- Выделите первую строку
- Данные → Создать фильтр

Это позволит быстро сортировать и фильтровать заявки.

### Сводные таблицы

Создайте сводные таблицы для анализа:
- По источникам (UTM Source)
- По типам устройств
- По городам участников
- По пакетам партнёров

## Проверка работы

После создания листов проверьте:

1. Откройте страницу `/projects/wakesurf-safari`
2. Заполните любую форму (участник, партнёр, медиа, фидбек)
3. Отправьте форму
4. Проверьте, что данные появились в соответствующем листе Google Sheets
5. Проверьте, что пришло уведомление в Telegram (если настроено)
6. Проверьте, что все колонки заполнены корректно
